# Menoteam

An early worldview for a philosophy-driven autonomous work framework.

Menoteam explores how agents can learn from human philosophy, experience, judgment, and taste, then use that foundation to discover goals, seek context, act over time, ask better questions, evaluate outcomes, and grow with humans.

This repository starts as a thinking artifact, not a product spec. The first document is:

- [Worldview Manifesto v0.1](docs/worldview-manifesto-v0.1.md)
- [Idea Bank](docs/idea-bank.md)
- [Reference Wiki](docs/wiki/README.md)

## Name

`Menoteam` is a working name for autonomous work systems that grow with human judgment.

It emphasizes collaborative growth and autonomous execution without binding the system to a fixed model, role, or task type.

## Current Framing

Menoteam is not a fixed workflow, agent runtime, task manager, or company simulator.

The framework should help agents form an operating philosophy from human interaction and history, then use that philosophy to guide autonomous work. When context is available, the system should keep working. When context is missing or responsibility needs human judgment, it should ask. Over days or weeks of work, goals, decisions, actions, questions, artifacts, evaluations, and reflections should remain traceable.
